содержат официального построчного словаря признаков, поэтому смысловые описания
ниже являются интерпретацией английских названий, а не цитатой организаторов.

## Наблюдаемые связи между исходными признаками

Это описательный анализ, а не доказательство причинности:

- корреляция `daily_screen_time_hours` с `weekend_screen_time`: `0.800`;
- с `social_media_hours`: `0.596`;
- с `work_study_hours`: `0.526`;
- с `gaming_hours`: `0.429`;
- сумма `social_media_hours + gaming_hours + work_study_hours` ни в одной из
  421 427 строк без нужных пропусков не превышает `daily_screen_time_hours`;
- медианная доля этой суммы в общем экранном времени — около `88.5%`;
- следовательно, разница между общим временем и суммой трёх известных типов
  похожа на отдельное «прочее экранное время».

Слабая линейная корреляция не означает бесполезность. Например,
`notifications_per_day` и `app_opens_per_day` получили заметную важность в
CatBoost. Возможные объяснения: пороги, нелинейная форма или взаимодействия.

## Кандидаты для обсуждения feature engineering

Это банк гипотез, а не список уже одобренных изменений:

- `weekend_screen_time - daily_screen_time_hours` — изменение поведения в выходные;
- `social_media_hours + gaming_hours + work_study_hours` — учтённое экранное время;
- `daily_screen_time_hours - social_media_hours - gaming_hours - work_study_hours`
  — прочее экранное время;
- `(social_media_hours + gaming_hours) / daily_screen_time_hours` — доля развлечений;
- `work_study_hours / daily_screen_time_hours` — доля работы и учёбы;
- `app_opens_per_day / daily_screen_time_hours` — интенсивность переключений;
- `notifications_per_day / daily_screen_time_hours` — плотность уведомлений;
- `app_opens_per_day / notifications_per_day` — условный отклик на уведомления;
- `daily_screen_time_hours / sleep_hours` — соотношение экрана и сна;
- число пропущенных значений в строке — возможный паттерн генерации данных.

Для отношений нужно заранее определить обработку пропусков и деления на ноль.
Каждый новый признак должен проверяться на неизменной схеме валидации.
