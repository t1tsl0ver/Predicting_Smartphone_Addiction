# trial-010 — Other screen time

- Статус: **accepted**
- Дата: 2026-08-14
- Контроль: `trial-009`

## Вопрос

Поможет ли LightGBM явно рассчитанное прочее экранное время, которое остаётся
после вычитания трёх известных видов активности из общего времени?

## Гипотеза

```text
other_screen_time_hours =
    daily_screen_time_hours
    - social_media_hours
    - gaming_hours
    - work_study_hours
```

Все компоненты измеряются в часах и ведут себя как части одного общего бюджета:
на строках без нужных пропусков сумма трёх частных значений не превышает общее
экранное время. Маленький остаток означает, что большая часть дня объясняется
явными активностями. Гипотеза участника: меньший остаток связан с большей
вероятностью зависимости.

Явный residual также может быть проще для деревьев, чем самостоятельное
приближение разности четырёх колонок множеством axis-aligned splits.

## Единственное основное изменение

Добавляется одна колонка `other_screen_time_hours`. Если отсутствует хотя бы один
из четырёх компонентов, значение остаётся `NaN`; пропуски не заменяются нулями.

## Что остаётся неизменным

```text
model=LGBMClassifier
n_estimators=500
learning_rate=0.1
num_leaves=31
min_child_samples=20
reg_alpha=0.0
reg_lambda=0.0
folds=5
shuffle=True

```

## План проверки

- использовать те же folds, что в `trial-009`;
- сравнить общий raw OOF AUC и fold-wise deltas;
- проверить наблюдаемое направление связи residual с target;
- принять фичу при положительном общем delta и победе минимум на 3/5 folds.

## Команда

```powershell
.\.venv\Scripts\python.exe src\cv_lightgbm.py --run-id trial-010 --drop-features gender stress_level --add-other-screen-time --submission submission_trial-010.csv
```

## Проверка направления связи

На `421427` train-строках, где residual можно вычислить:

- Pearson correlation с target: `+0.30499`;
- Spearman correlation с target: `+0.41662`;
- доля `addicted_label=1` по квинтилям residual растёт примерно так:
  `0.429 → 0.572 → 0.724 → 0.887 → 0.934`.

Таким образом, исходная гипотеза о направлении связи не подтвердилась: в этих
данных с зависимостью связан не меньший, а больший остаток экранного времени.
Это наблюдаемая корреляция, а не причинный эффект.

LightGBM действительно использует новую колонку: её средний gain importance
равен `16.73 млн`, девятое место из одиннадцати признаков.

## Решение

Фича **принята**: общий raw OOF вырос на `+0.0004036`, победа получена на 4/5
folds. При этом объяснение фичи следует скорректировать: полезен сам residual,
но фактическое направление связи оказалось обратным первоначальному ожиданию.
