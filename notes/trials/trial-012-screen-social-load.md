# trial-012 — Joint screen and social-media load

- Статус: **accepted**
- Дата: 2026-08-14
- Контроль: `trial-010`

## Вопрос

Поможет ли LightGBM явное взаимодействие общего экранного времени и времени в
социальных сетях?

## Гипотеза

```text
screen_social_load = daily_screen_time_hours * social_media_hours
```

Высокое значение требует одновременно достаточно большого общего экранного
времени и заметного времени в соцсетях. Произведение представляет непрерывную
совместную нагрузку без произвольных порогов «высокого» значения и позволяет
дереву использовать её одним split вместо ступенчатого приближения взаимодействия
двух исходных колонок.

Предварительная описательная проверка показала одномерный AUC около `0.90` внутри
каждой категории gender. Связь не является специфичной для женщин, поэтому в
этом trial используется общий product, а `gender` остаётся исключённым.

## Единственное основное изменение

К принятому набору `trial-010` добавляется одна колонка `screen_social_load`.
Если отсутствует любой из двух компонентов, значение остаётся `NaN`.

## Что остаётся неизменным

```text
model=LGBMClassifier
n_estimators=500
learning_rate=0.1
num_leaves=31

reg_alpha=0.0

```

## План проверки

- использовать те же folds, что в `trial-010`;
- сравнить общий raw OOF AUC и fold-wise deltas;
- принять фичу при положительном общем delta и победе минимум на 3/5 folds.

## Команда

```powershell
.\.venv\Scripts\python.exe src\cv_lightgbm.py --run-id trial-012 --drop-features gender stress_level --add-other-screen-time --add-screen-social-load --submission submission_trial-012.csv
```
