# Project notes

Эта папка — постоянная память проекта для участника и любого нового рабочего
сеанса с ассистентом.

Читать в таком порядке:

1. [`CURRENT_STATE.md`](CURRENT_STATE.md) — где мы сейчас и что делать дальше;
2. [`DATA_DICTIONARY.md`](DATA_DICTIONARY.md) — все исходные признаки и факты о них;
3. [`EXPERIMENT_RULES.md`](EXPERIMENT_RULES.md) — как формулировать и сравнивать эксперименты;
4. [`TRIALS.md`](TRIALS.md) — реестр маленьких проверок;
5. [`EXPERIMENTS.md`](EXPERIMENTS.md) — реестр итоговых версий;
6. `trials/` — подробные карточки маленьких проверок;
7. `experiments/` — итоговые версии из нескольких принятых улучшений.

Заметки хранят решения и причины, а не только итоговые числа. После каждого trial
нужно обновить его карточку и текущее состояние; после итогового exp — ещё и реестр.
