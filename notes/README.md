# Project notes

Эта папка — постоянная память проекта для участника и любого нового рабочего
сеанса с ассистентом.

Читать в таком порядке:

1. [`CURRENT_STATE.md`](CURRENT_STATE.md) — где мы сейчас и что делать дальше;
2. [`EXPERIMENT_RULES.md`](EXPERIMENT_RULES.md) — как формулировать и сравнивать эксперименты;
3. [`EXPERIMENTS.md`](EXPERIMENTS.md) — краткий реестр результатов;
4. `experiments/` — подробные карточки отдельных запусков.

Заметки хранят решения и причины, а не только итоговые числа. После каждого
завершённого эксперимента нужно обновить его карточку, реестр и текущее состояние.
