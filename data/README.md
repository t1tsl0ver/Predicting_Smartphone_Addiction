# Local competition data

Положи сюда скачанные с Kaggle файлы под следующими именами:

```text
train.csv
test.csv
sample_submission.csv
```

CSV игнорируются Git: они крупные и должны распространяться через страницу
соревнования. Этот README остаётся в репозитории, чтобы после клонирования была
понятна ожидаемая структура.
